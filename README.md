# me - アンティーク家具販売サイト

アンティーク家具のオンライン販売サイトです。

## 機能

- 商品一覧の表示・検索
- 商品詳細ページ（写真・説明・価格）
- カート・購入機能
- お問い合わせフォーム

## 使い方

### セットアップ

1. リポジトリをクローンします：

```bash
git clone https://github.com/kabe7171/me.git
cd me
```

2. 依存関係をインストールします：

```bash
npm install
```

3. 開発サーバーを起動します：

```bash
npm run dev
```

ブラウザで `http://localhost:3000` にアクセスして表示を確認できます。

### 開発

```bash
# 新しいブランチを作成して作業を開始
git checkout -b feature/your-feature

# 変更をコミット
git add .
git commit -m "変更内容の説明"

# リモートにプッシュ
git push -u origin feature/your-feature
```
